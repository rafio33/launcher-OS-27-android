# iOS 27 Spatial Launcher (Android 14)

Launcher Android bertema **iOS 27 Spatial** dengan ekosistem lengkap sesuai referensi desain:
- **Dynamic Island Interaktif (9+ Mode):** Desain kapsul hitam murni dan melayang di bagian atas layar **tanpa jam atau sinyal yang mengapit bar**, persis sesuai screenshot referensi.
- **Kontrol Musik Interaktif Langsung di Bar:** Bisa langsung memutar (Play) dan menghentikan (Stop/Pause) musik langsung dari Dynamic Bar.
- **Reaksi Otomatis Dynamic Island:** Saat membuka Kamera, Navigasi/Maps, Timer, Telepon, Translate/AI, dll., Dynamic Island langsung bereaksi dan menampilkan status aktivitas tersebut.
- **Persistensi Musik saat Kembali ke Home:** Ketika kembali ke menu awal (Home Screen) dan musik sedang diputar, Dynamic Island tetap memainkan musik secara aktif dan tombol Play/Stop tetap bisa digunakan.
- **Tampilan Home Screen iOS 27:** Dilengkapi jam besar `9:41`, tanggal `Monday, September 15`, dua widget glassmorphism (Cuaca Jakarta 28° dan Agenda Kalender "Today"), kisi ikon aplikasi modern, serta Glass Dock di bagian bawah.
- **Fitur Ekosistem Lengkap (Image 2):**
  - **Quick Panel (Control Center):** Pengaturan Wi-Fi, Bluetooth, Airplane, Cellular, slider Brightness & Volume, kartu pemutar musik, dan tombol pintasan cepat.
  - **Lock Screen:** Layar kunci dengan Dynamic Island panggilan masuk dari Raka, jam besar 9:41, dan gesture geser untuk membuka kunci.
  - **Recent Apps:** Tampilan multitasking kartu melayang dengan efek blur dan tombol *Close all*.
  - **13 Aplikasi Simulasi Lengkap:** Settings, Phone, Messages, Gallery, Camera, Music, Browser, Weather, Calendar, Files, Notes, Calculator, dan AI Assistant (Gemini).

## 9 Mode Dynamic Island yang Didukung:
1. **Putar Musik:** Menampilkan album art, judul lagu (*Sweater Weather - The Neighbourhood* / *Adele Someone Like You*), equalizer animasi, serta tombol Play/Stop langsung di bar.
2. **Navigasi:** Petunjuk arah langkah demi langkah (*200 m Turn right*) dengan ikon Maps.
3. **Timer & Stopwatch:** Menampilkan sisa waktu hitung mundur (*Timer 00:14*) dengan tombol jeda/lanjut oranye.
4. **Rekam Video / Audio:** Durasi perekaman aktif (*🔴 00:05*) dengan gelombang suara merah.
5. **Live Activities (GoFood):** Status pesanan real-time (*GoFood - Pesanan dalam proses, 12 min*) lengkap dengan kartu pelacakan progress.
6. **Face ID:** Notifikasi visual pemindaian wajah (*Face ID - Look at your iPhone*).
7. **Pengisian Daya:** Indikator pengisian baterai (*⚡ Charging 78%*) dengan cincin MagSafe.
8. **Terjemahan Langsung:** Terjemahan percakapan real-time (*Live Translate - English ↔ Indonesian*).
9. **Focus Mode:** Status mode fokus aktif (*Focus - Do Not Disturb*).
10. **Panggilan Masuk / Berlangsung:** Informasi penelepon (*Raka - Incoming call...* / *📞 0:08*).

## Cara Mendapatkan File `.apk` via GitHub Actions:
1. Buat repository baru di GitHub (pilih **Public** agar kuota GitHub Actions gratis tanpa batas).
2. Upload / push semua file dan folder proyek ini (termasuk folder `.github`) ke repository tersebut.
3. Buka tab **Actions** di repository GitHub Anda.
4. Klik workflow **Build iOS 27 Spatial Launcher APK** yang sedang berjalan, tunggu sekitar **2 - 3 menit** hingga centang hijau ✅.
5. Unduh file APK dari bagian **Artifacts** di bagian bawah halaman workflow: **`iOS27-Spatial-Launcher-APK`**.

> 💡 **Penting Sebelum Menginstal:** Jika sebelumnya sudah ada versi lama di HP, hapus (uninstall) aplikasi lama terlebih dahulu agar sistem Android memasang pembaruan paket dengan bersih.
